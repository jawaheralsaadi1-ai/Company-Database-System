## Company Database System: Implementation Journey

##  Project Scope
This project involves designing and implementing a relational database for a large company to manage employees, departments,
and projects. The solution is based on a specific business case study.

##  Tech Stack
- **Database Engine:** Microsoft SQL Server (SSMS 2022)
- **Language:** T-SQL
- **Methodology:** Requirement Analysis -> ERD -> Relational Mapping -> SQL Coding

##  Workflow Steps
1. **Requirement Analysis:** Identified entities like Employees, Departments, and Projects from the case study.
2. **ERD Design:** Created a visual Entity-Relationship Diagram to define relationships.
3. **Relational Mapping:** Translated the ERD into a structured table schema.
4. **SQL Implementation:** Developed T-SQL scripts to create tables.

##  Repository Structure
- Design/: Whiteboard photos of the ERD and Mapping.
- Scripts/: T-SQL scripts for schema and data.
